# 🔗 LinkVault — Chrome Extension

**Save your profile links once. Access them whenever you need them.**

LinkVault is a lightweight Chrome extension designed to help users manage their personal profile URLs and quickly fill matching fields in online forms.

## ✨ Features

* **Save Profile Links:** Store links for LinkedIn, GitHub, portfolio, personal website, resume, Instagram, and custom URLs.
* **Quick Copy:** Copy saved links whenever you need them.
* **Smart Autofill:** Identify matching form fields and fill them using saved profile links.
* **Local Storage:** Keep saved links in Chrome's local extension storage.
* **Import & Export:** Back up and restore your saved links using JSON.
* **Lightweight:** Built with HTML, CSS, and JavaScript using Chrome Extension Manifest V3.

## 📥 Installation

1. Download or clone this repository.
2. If downloaded as a ZIP, extract the folder.
3. Open Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing `manifest.json`.

LinkVault should now appear in your Chrome extensions.

## 🔒 Privacy

LinkVault is designed to store saved profile links locally using Chrome extension storage. Review the source code and extension permissions before use.

Autofill behavior depends on the structure of the website's form fields. Always review the information before submitting a form.
